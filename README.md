# GINO’S II — Waack Me Up (Vite + React + Tailwind)

## Local
```bash
npm install
npm run dev
```
Open http://localhost:5173

## Build
```bash
npm run build
npm run preview
```

## Deploy (Vercel)
1. Importa questo repo su Vercel
2. Build Command: `npm run build`
3. Output Directory: `dist`

## Deploy (GitHub Pages)
Aggiungi eventualmente `base` al vite.config.js e pubblica la cartella `dist`.
